# Security Policy

## Supported versions

HermesKey is young. Security fixes are expected to land on the latest `main` branch and the most recent tagged release.

## Reporting a vulnerability

Please do **not** open a public issue for security-sensitive problems.

Instead, report privately through GitHub security advisories or a private maintainer contact path.

When reporting, include:

- affected version or commit
- reproduction steps
- impact assessment
- any proposed mitigation if known

We will aim to acknowledge reports quickly and coordinate a fix before public disclosure when possible.
