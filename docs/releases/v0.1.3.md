# HermesKey v0.1.3

HermesKey is a push-to-talk speech-to-text tool for Linux Wayland desktops.

This release tightens the project into something that feels more like a real product and less like a personal script bundle.

## Highlights

- polished bootstrap installer
- one-line install path
- distro-specific install guidance
- user-service based Wayland typing workflow
- built-in diagnostics with `hermeskey-doctor`
- cleaner README and documentation structure

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash
```

Install from `main` instead of the latest tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash -s -- --main
```

## What HermesKey does

- toggle start/stop recording with one hotkey
- keep `faster-whisper` warm in a background service
- show a lightweight overlay for recording/transcribing state
- type directly into the active app
- keep clipboard backup as a safety net
- use paste fallback for terminal-style targets

## Notes

HermesKey is currently tuned primarily for KDE Plasma on Wayland with PipeWire.
