# HermesKey v0.3.0

HermesKey is a push-to-talk speech-to-text tool for Linux Wayland desktops.

This release pushes the project further toward a real desktop tool by tightening command behavior, improving installer ergonomics, and adding a first-pass desktop integration story.

## Highlights

- `hermeskey` now works like a cleaner CLI tool with `--help`, `--version`, `--status`, and `--doctor`
- desktop launcher helpers for status, diagnostics, and config access
- AppStream metadata and desktop entry scaffolding
- packaging direction docs and refreshed RPM / AUR starter files
- improved bootstrap and install output

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash
```

Install from `main` instead of the latest tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash -s -- --main
```

## Notes

HermesKey is still primarily tuned for KDE Plasma on Wayland with PipeWire, but the project now includes the first pass of a desktop-launcher and packaging story.
