# HermesKey v0.4.0

HermesKey is a push-to-talk speech-to-text tool for Linux Wayland desktops.

This release sharpens the desktop experience around the core hotkey workflow and makes the project feel more like a complete Linux utility.

## Highlights

- desktop control-center helper for status, diagnostics, logs, config access, and service restart
- richer desktop integration with additional launchers
- better service and log inspection tools from the app-menu side
- continued packaging and distribution groundwork

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash
```

Install from `main` instead of the latest tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash -s -- --main
```

## Notes

HermesKey remains hotkey-first. The desktop launchers are support tools around the main dictation loop, not a replacement for binding `~/.local/bin/hermeskey` directly.
