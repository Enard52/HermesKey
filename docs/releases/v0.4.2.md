# HermesKey v0.4.2

HermesKey is a push-to-talk speech-to-text tool for Linux Wayland desktops.

This is a bug-fix and privacy release. **Upgrading is recommended**: earlier versions left your last voice recording in `/tmp`, readable by every user on the machine.

## Highlights

- **Private recordings**: audio goes to `$XDG_RUNTIME_DIR` (owner-only, in memory) and is deleted after transcription (#18)
- **Private logs**: logs moved from `/tmp` to `~/.local/state/hermeskey/` (#18)
- **Socket permissions**: the speech server socket is owner-only from the moment it's created (#22)
- **No more `eval`**: window info is parsed as plain data (hardening; #19)
- **Better error messages**: typing failures show the real reason, e.g. "ydotoold not running" (#25)

## Upgrading

Re-run the installer:

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash
```

The installer also deletes old `/tmp/hermeskey_audio.wav` and `/tmp/hermeskey*.log` files. Your config file is not changed.

## Notes

- Logs are now at `~/.local/state/hermeskey/hermeskey.log`. If you set `LOG` or `WAV` in `hermeskey.env`, those values are still used.
- Set `KEEP_AUDIO=1` in `hermeskey.env` to keep the last recording for debugging.
