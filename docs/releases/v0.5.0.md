# HermesKey v0.5.0

HermesKey is a push-to-talk speech-to-text tool for Linux Wayland desktops.

This release fixes active window detection, makes the terminal paste fallback work, and types about 4x faster.

## Highlights

- **Terminal paste fallback works.** Dictating into WezTerm, Konsole, kitty and other terminals now pastes with `Ctrl+Shift+V` instead of typing. Before, the fallback never triggered (#28).
- **No more crosshair cursor.** With `FOCUS_SAFE_MODE=1`, every hotkey press used to open KWin's interactive window picker. HermesKey now detects the active window without it, using `kdotool` if installed or a built-in KWin script otherwise (#28).
- **Faster typing.** Each key is now held for 5 ms instead of ydotool's 20 ms default. Adjust with `TYPE_KEY_DELAY` / `TYPE_KEY_HOLD` (#34).
- **No duplicate speech server** when you press the hotkey while the model is still loading (#27).
- **Your clipboard is safe.** It is no longer wiped when nothing was captured, and `COPY_TO_CLIPBOARD=0` is respected (#31).
- **Language auto-detect works** with `STT_LANG=` (empty) (#30).
- **Custom venv locations** (`HERMESKEY_VENV`) work end to end (#32).

## Upgrading

Re-run the installer. It now restarts the HermesKey services for you:

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash
```

Your existing `~/.config/hermeskey/hermeskey.env` is not changed.

## Notes

- **Default microphone:** new installs record from `default`, your desktop's default input. Existing configs that set `RECORD_SOURCE` keep their value. `hermeskey-doctor` now warns if the configured microphone does not exist.
- **Fedora/Nobara:** the overlay needs `python3-pyside6`. Earlier docs listed `python3-qt6`, which is PyQt6.
- **Free disk space:** PySide6 is no longer installed into the venv, because the overlay uses the system Python. To remove an existing copy (~670 MB): `~/venvs/stt/bin/pip uninstall PySide6`
- **If an app drops characters while typing,** set `TYPE_KEY_HOLD=20` in your config.
