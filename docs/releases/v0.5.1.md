# HermesKey v0.5.1

HermesKey is a push-to-talk speech-to-text tool for Linux Wayland desktops.

This release gives HermesKey its own icon. There are no changes to dictation behaviour.

## Highlights

- **New app icon:** a winged keycap. One key (your hotkey) with voice bars, plus a Hermes wing.
- **Desktop integration:** the installer adds the icon to your user icon theme, and the HermesKey launchers (Control Center, Status, Doctor, Logs, Config) use it instead of generic system icons.
- **README hero banner** and a GitHub social preview image.

## Upgrading

Re-run the installer:

```bash
curl -fsSL https://raw.githubusercontent.com/graygarbage/HermesKey/main/scripts/bootstrap.sh | bash
```

If the launchers still show the old icons, log out and back in so the desktop refreshes its icon cache.
